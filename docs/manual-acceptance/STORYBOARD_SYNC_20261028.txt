운영 반영시
- 이 Git 변경은 소스·테스트·마이그레이션 파일이다. 로컬 검수 DB/업로드·.env는 복사하지 않는다.
- 운영 DB의 기존 회원·소셜 연결·회원사·관리자 데이터가 그대로 표시된다.
- 배포 절차에서 기존 DB 백업 후 php artisan migrate --force 등 프로젝트 배포 절차 적용 필요.
- 검수 화면 활성화는 기존 STORYBOARD_TEST_ENABLED 설정 사용. 기본값 비활성 유지.
- 기존 STORYBOARD_FRONT_URL / STORYBOARD_ADMIN_URL은 해당 서버 도메인 설정 사용.
- 검수 비밀번호는 서버 .env에만 저장하며 Git에 실제 값을 넣지 않는다.
  공통 STORYBOARD_TEST_PASSWORD 또는 STORYBOARD_MEMBER_PASSWORD,
  STORYBOARD_CHANNEL_MEMBER_PASSWORD, STORYBOARD_DISTRIBUTOR_PASSWORD, STORYBOARD_ADMIN_PASSWORD.
- 잘못된 설정 비밀번호는 표시하지 않고 선택 계정과 불일치라고 표시한다.
- 이번 작업은 운영서버 배포를 수행하지 않음.
