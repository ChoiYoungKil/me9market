- 로컬 Google 개발 예외와 HTTPS Google 인증 경로 유지.
- Naver 운영 HTTP 콜백 허용. 기존 host/port/path/state/계정 연결 검증 유지.
- 회원 및 Shop 공통 로그인 버튼과 계정 연결 화면에 적용.
- 프런트 .env 두 제공자 활성화, Naver 콜백 HTTP로 변경. 기존 키와 다른 설정 보존.
- Google 콜백은 기존 HTTPS 유지. 관리자 서버 OAuth는 비활성 상태 유지.
