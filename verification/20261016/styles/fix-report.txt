Me9 페이지 스타일 및 관리자 배송비 화면 수정
검증일: 2026-10-16 KST

해결한 원인
관리자 배송비 메뉴는 Shop 주문 계산과 별개인 국가·무게별 ShippingCharge 구형 화면을 열고 있었다.
관리자 메뉴 이동 시 Skydash 구형 레이아웃과 현재 Me9 레이아웃이 섞였고, 관리 포털에 최소 너비 1200px 및 팝업 최소 너비 1024px가 남아 있었다.
마이페이지 모바일 헤더 고정 위치, 표의 tbody만 블록으로 전환하는 규칙, 검색창의 고정 너비가 겹침·줄바꿈·넘침을 만들었다.

수정
/admin/shipping-charges: 판매자별 현재 ChannelDeliveryCharge 정책 목록·검색·등록으로 교체.
/admin/edit-shipping-charges/{id}: 현재 배송비 정책 수정 화면으로 교체.
무료·조건부·고정·변동·구간·지역 조건을 채널 관리자와 같은 입력 폼/검증 서비스로 저장한다.
저장한 정책은 상품의 shipping_policy_id를 통해 실제 Shop 주문 계산에 연결된다.
배송비 유형에 해당하는 입력만 표시하며 구간 추가/삭제, 지역 권역별 입력, 오류 메시지를 연결했다.
판매자 계정은 기존 관리자 영역 제한을 유지하며 채널 배송비 화면에서 자신의 정책을 관리한다.
구형 국가·무게 배송비 데이터는 새로운 Shop 정책으로 임의 변환하지 않았다.

구형 관리자 콘텐츠도 현재 Me9 헤더·사이드바로 통일했다. 구형 폼이 사용하는 Bootstrap 스타일은 콘텐츠 내부로 범위를 제한하여 공통 레이아웃과 충돌하지 않게 했다.
기존 jQuery를 다시 로드하지 않고 필요한 Bootstrap/Popper 및 DataTables만 로드한다.
관리 메뉴에 섹션·브랜드·필터·배너·리뷰·쿠폰 진입점을 유지했다. 신규 배송비 설정 활성 상태도 표시한다.
관리자/채널/회원 레이아웃의 CSS 및 스크립트 스택 위치, CSRF 메타, 모바일 viewport를 정리했다.
공통 헤더/검색/카드/버튼을 좁은 화면에서 재배치하고 넓은 표는 표 영역 안에서 가로 스크롤하게 했다. 문서 전체를 잘라내는 방식으로 넘침을 숨기지 않았다.
배송비 팝업을 헤더 위에 표시하고 모바일에서도 폼·닫기 버튼에 접근하도록 했다.
마이페이지 헤더·메뉴·포인트 표·날짜 필터를 수정하고 누락된 닫기/검색/달력 이미지 경로를 정리했다.
관리자/채널 로그인 카드의 중첩과 고정 최소 너비를 제거했다.
발주사 화면의 메뉴·본문·표에 반응형 배치를 적용했다.
샘플 2021년 날짜 선택기와 실제 페이지 이동이 없는 포인트 샘플 번호 1~5를 제거했다.
공통 자산 URL에 파일 수정 시각을 붙여 수정된 CSS/JS를 다시 받게 했다.
CSS 빌드는 임시 storage/framework/views를 스캔하지 않게 하여 캐시 상태에 따라 결과가 변하지 않도록 했다.
관리자 호환 CSS/JS 생성은 scripts/build-admin-compat.cjs 및 npm run build에 포함했다.

검증 범위
격리된 newme9markte_testing DB에서 역할별 테스트 데이터를 만들고 Laravel HTTP 렌더 결과를 추출해 Chrome에 표시했다.
배송비 유형 전환·팝업·메뉴는 브라우저 상호작용으로 확인했고, 저장·권한·주문 계산은 HTTP 회귀 테스트로 확인했다.
운영 사용자 데이터·모든 데이터 조합·모든 브라우저·모든 예외 상태에 대한 전수 인수를 의미하지 않는다.
