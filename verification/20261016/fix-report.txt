수정 내용
1. 회원가입
/register/member, /register, Shop 가입에서 RegistrationConsent 서비스를 공통 사용한다.
필수 동의 3개는 accepted 검증을 통과해야 한다. 운영 환경에서 HTTPS 정책 문서 URL 3개와 버전이 없으면 사용자 생성·로그인을 차단한다.
동의 시각·문서 URL·버전·필수/선택 동의 값을 users에 저장한다. 선택 동의 안내 문서가 없는 운영 환경에서는 선택 동의를 차단한다.
일반 가입 화면의 샘플 약관을 설정된 문서 링크로 교체하고 선택 동의도 저장한다. 프런트 비밀번호 안내와 검증을 서버의 12자 기준에 맞췄다.
기본 가입 화면에도 필수 동의 입력과 정책 미준비 안내를 추가했다.
기존 비활성 legacy API, 미연결 구형 컨트롤러까지 활성 서비스로 전환하지 않았다.

2. 배송비
상품에 shipping_policy_id를 추가하고 판매자 소유·활성 정책만 선택할 수 있게 했다.
기존 정책명은 같은 판매자 안에서 유일한 경우 새 식별자로 연결한다. 동명 중복 정책은 추측하지 않으며 상품에서 식별자를 다시 선택해야 한다.
수량 무료 조건, 금액 무료 조건(둘 중 하나 충족 시 무료), 반복 금액/수량 부과, 1부터 반복 시작, 지역 추가금 반복, 금액/수량 구간, 제주/도서산간 제한, 2권역/3권역 추가금을 구현했다.
구간은 하한 이상·상한 미만으로 적용한다. 0부터 연속되어야 하며 중복/공백을 거절하고 마지막 구간의 상한은 비워 둔다.
정책 적용 범위는 상품별이며 옵션 행의 수량과 금액을 합산한다. 같은 정책을 쓰는 서로 다른 상품을 자동 묶음배송으로 간주하지 않는다.
장바구니는 주소 미확정 기본 배송비를 계산한다. 주문 화면에서 주소와 우편번호를 입력하면 서버 견적으로 지역 추가금을 반영한다.
주문 시 서버에서 다시 계산하고 화면에서 확인한 금액과 다르면 거절한다. 배송 제한은 착불에도 적용한다.
주문 품목 shipping_amount_snapshot과 settlement_policy_snapshot.shipping_policy에 계산 금액과 당시 정책을 보존한다.
사용 중인 정책 삭제를 차단한다. 관리 입력·조회·수정 화면에 새 조건을 연결했다.

지역 판정 전제
제주/도서산간 우편번호와 범위는 판매자가 택배사 기준으로 등록한다. 지역 추가금 또는 제한을 켜면서 필요한 목록을 비워 두는 입력은 거절한다.
실제 운영 택배사의 승인된 우편번호 데이터는 제공되지 않아 등록하지 않았다. 테스트 우편번호는 테스트 데이터다.
제주가 주소에 표시된 경우도 제주로 처리하지만, 전국 도서산간 주소 정확도 인수는 실제 택배사 목록 등록 후 필요하다.
반복 기준 N의 기본 모드는 N, 2N, 3N에서 추가한다. '1부터 시작'은 1, N+1, 2N+1에서 추가한다. 기본 배송비에 추가하며 지역 배송비는 최초 1회와 선택된 반복 횟수에 따라 별도로 부과한다.

3. 마이페이지
채널 바로가기와 QR에 각 channel_code를 포함한 shop.enter 주소를 사용한다. 비공개 채널은 기존 입장/OTP 접근 제어를 유지한다.
공통 헤더도 PointTransaction 원장 합계를 표시한다. 샘플 채널은 방문 및 포인트 기록에 해당하는 실제 채널로 교체했다.
샘플 사업자 정보는 제거하고 storefront 설정을 표시하며 약관/개인정보 링크는 shop_channel의 문서 URL로 연결한다.
실제 승인 사업자 정보와 정책 문서의 운영 설정은 별도로 필요하다.
